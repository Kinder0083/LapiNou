# LapiNou — plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Transformer le Karotz en assistant vocal familial « Lapinou » : fork de LapinLibre (MQTT/Home Assistant, écoute continue, page de réglages, mode sans serveur, OTA) + serveur LapiNou (mot d'activation, transcription, cerveau interchangeable, outils, mémoire, voix) + installateur Proxmox en un script.

**Architecture:** Le lapin reste un « corps » : ses démons LapinLibre, plus quatre démons `lapinou-*` (micro, MQTT, mode sans serveur, OTA) et une page de réglages. Le serveur Python, dans un LXC Proxmox, reçoit le flux micro, fait mot d'activation + annulation d'écho + VAD + Parakeet, appelle le cerveau (Claude / compatible OpenAI / repli Assist) avec ses outils (ha-mcp, Lyrion, minuteurs, mémoire, recherche web), synthétise la voix et pilote le lapin par le **protocole plateforme de LapinLibre** (port 9123). Home Assistant voit le lapin par MQTT.

**Tech Stack:** Firmware : Buildroot 2026.02.3, GCC 14.3, uClibc-ng 1.0.57, C gnu99 / C++ gnu++17, D-Bus (dbus-glib), protobuf 2.3.0, BusyBox httpd + CGI shell, paho-mqtt-c, SpeexDSP, libcurl, OpenSSL. Serveur : Python 3.12, uv, asyncio, FastAPI + Uvicorn, SQLite, sherpa-onnx (Parakeet TDT 0.6B v3 int8 + Silero VAD), openWakeWord, Kokoro-onnx / Piper, SpeexDSP (binding Python), SDK `anthropic`, SDK `openai`, client MCP `mcp`, paho-mqtt. Installateur : bash pour Proxmox (`pct`, `pveam`). CI : GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-11-15-lapinou-design.md` (approuvée le 2026-11-16). L'exécutant lit la spec et ce plan.

## Global Constraints

- Noyau **2.6.32** de LapinLibre ; pas de 6.1.
- **Jamais d'écriture** dans mtd0 (chargeur) ni mtd3, mtd4, mtd5 (secours). Écritures autorisées : mtd1 (noyau ≤ 3 Mio), mtd2 (rootfs ≤ 5 Mio, gzippé et décompressé), mtd6 (`/usr`, YAFFS 234 Mio).
- Nos ajouts sur le lapin vont dans `/usr`, pas dans le rootfs.
- Chaque fichier porte un `SPDX-License-Identifier` dans ses 5 premières lignes, fins de ligne LF, pas de lien symbolique dans le dépôt (`scripts/check-repo.py` doit passer). Nos ajouts : `MIT`.
- Toute nouvelle bibliothèque du firmware : téléchargement épinglé SHA-256 dans `config.toml [download.*]`, entrées dans `system/core-files.txt`, `tests/expected/key-files.txt` mis à jour.
- Nouveaux démons : `userland/src/usr/lapinou-<nom>/`, déclarés dans `userland/Makefile` (`DAEMONS`, `<nom>_PREFIX`, `<nom>_LIBS`, `ARM_ONLY` si besoin), démarrés par `image/core/usr/etc/init.d/S40lapinlibre` sous `immortaldog`.
- Audio du lapin vers le serveur : **16 kHz, mu-law 8 bits, mono**, sans décimation.
- Seul du **texte** quitte la maison en mode serveur ; aucun audio n'est envoyé sur internet en mode serveur.
- Modèle LLM par défaut `claude-opus-5-5`, modèle rapide `claude-haiku-5-5` ; requêtes Anthropic avec `fallbacks: "default"` (beta `server-side-fallback-2026-07-01`) et contrôle de `stop_reason == "refusal"`.
- Budget mensuel : à **80 %** bascule vers le modèle rapide ; à **100 %** repli Home Assistant.
- Actions sensibles (domaines `lock`, `alarm_control_panel`, `cover` de type garage, entités marquées sensibles, `climate` hors plage) **désactivées par défaut** ; si activées : confirmation vocale (+ code PIN optionnel).
- Musique et radio vers **Lyrion (LMS)** par défaut ; le lapin ne devient pas un lecteur Squeezebox.
- Annulation d'écho **en v1**.
- Fenêtre de suite après une réponse : **5 s** ; fin de phrase VAD : **0,7 s** de silence ; enregistrement en mode sans serveur : **≤ 15 s**.
- Objectif de latence : début de réponse **≤ 3 s** après la fin de phrase pour une commande simple.
- Dépôt **privé** `Kinder0083/LapiNou`, branche `main`, amont `sweetlilmre/LapinLibre` en remote `upstream`.
- LXC par défaut : **4 cœurs, 6144 Mo, 20 Go**, non privilégié, démarrage automatique.
- Ports serveur : **9123** plateforme LapinLibre, **9300** flux micro LapiNou, **8080** HTTP (page de réglages + API + endpoints LapinLibre apps/grammaire + OTA), **8081** TTS compatible `voice-daemon`, **8443** ASR compatible `voice-daemon`.
- Interfaces en français d'abord ; textes dans des fichiers de traduction (`fr.json`).
- Mot de passe admin obligatoire sur toute page qui stocke ou affiche des secrets ; les secrets ne sont jamais renvoyés en clair à une page.

## Écart assumé par rapport à la spec (à signaler au propriétaire)

- §13.6 de la spec disait « gestes par MQTT » : le plan pilote le lapin depuis le serveur par le **protocole plateforme** existant (`Ears`, `Led`, `Multimedia`, `Choreography` dans `userland/proto/platform-message.proto`), déjà implémenté et testé par LapinLibre. MQTT sert à Home Assistant.
- §6.3 permettait l'AEC sur le lapin ou au serveur : le plan la fait **au serveur**, qui connaît exactement le son qu'il a fait dire au lapin (référence parfaite, pas de rééchantillonnage sur un ARM9 sans FPU). Le lapin marque dans le flux l'instant où la lecture commence. Repli sur l'AEC côté lapin seulement si la mesure de la Tâche 3 le rend nécessaire.

## Review Focus

1. **Wi-Fi qui décroche en pleine phrase** : le lapin se reconnecte seul (flux micro, plateforme, MQTT) sans redémarrer, et le serveur abandonne proprement la conversation en cours.
2. **Serveur redémarré** : les lapins se reconnectent en moins de 30 s, les minuteurs et rappels en cours sont conservés et annoncés à l'heure.
3. **Fausse détection de « Lapinou »** (télé, conversation) : sans parole dans les 5 s, retour au repos sans appel au LLM ni dépense.
4. **Home Assistant, Lyrion ou internet indisponible pendant une demande** : Lapinou le dit à voix haute en une phrase, le service ne plante pas.
5. **Caractères spéciaux dans les réglages** (guillemets, `$`, `;`, espaces, accents dans un mot de passe Wi-Fi ou MQTT) : enregistrés tels quels, sans injection de commande dans les CGI shell ni casse du fichier INI.
